# Multi-Agent AI Travel Planner

A student-friendly academic prototype demonstrating coordinated specialist agents, a genuine regression training/evaluation pipeline, Streamlit UI, SQLite persistence, and live Open-Meteo weather.

## Important data honesty
The included ML dataset is **synthetic supplementary data** generated by `ml/generate_dataset.py`. It is not presented as real booking data. The model metrics are real measurements obtained by actually training/testing on that dataset.

## Run on Windows PowerShell
```powershell
cd path\to\multi_agent_travel_planner
py -m venv .venv
.\.venv\Scripts\Activate.ps1
python -m pip install -r requirements.txt
python ml\generate_dataset.py
python ml\train.py
python -m pytest -q
python -m streamlit run app.py
```

## How to explain it in viva
1. The form creates a structured `TripRequest`.
2. Specialist agents separately estimate transport, hotel, activities and food.
3. The regression pipeline predicts total expenditure from destination, travellers, days, accommodation, transport, season, activity and meals.
4. The Budget Agent compares the ML prediction/estimates with the user's budget.
5. The Itinerary Agent creates a day-wise plan.
6. Open-Meteo supplies live weather, clearly separated from ML estimates.
7. SQLite stores generated trips.

## Regression algorithms compared
Linear Regression, Decision Tree Regressor, Random Forest Regressor, Gradient Boosting Regressor. Selection is by lowest test RMSE; MAE, MSE, RMSE and R² are saved in `ml/models/metrics.json`.

## Current limitation
The chatbot in this MVP explains current trip context but does not yet perform LLM-based natural-language state mutation. That should be added only after selecting an LLM provider/key and testing it; the project does not falsely claim that feature is complete.
